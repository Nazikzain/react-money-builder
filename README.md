# Money Builder

A personal finance dashboard built with React and Vite.

## Features

- Track income and expenses.
- Monitor total balance and savings rate.
- Manage monthly budgets and category limits.
- Set and track savings goals.
- View monthly financial reports.
- Analyze expenses by category.
- Manage and search financial transactions.
- Export and restore data backups.
- English and Arabic language support.
- Responsive user interface.

## Technologies

- React
- JavaScript
- Vite
- CSS
- Browser Local Storage

## Installation

1. Clone the repository.
2. Install dependencies:

   `npm install`

3. Start the development server:

   `npm run dev`

4. Build for production:

   `npm run build`

## Data Storage

The current version stores financial data locally in the browser using Local Storage.
